## Local Development

### Prerequisites
- Python 3.11+
- Node.js 18+
- Git

### Backend Setup

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS/Linux

pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env and add your API keys (at minimum: GROQ_API_KEY)

# Run migrations
alembic upgrade head

# Start server
uvicorn app.main:app --reload --port 8000
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) → navigate to **AI Assistant** → select **ZeroDay AI**.

## Deployment

### Backend → [Render](https://render.com)

1. Push this repo to GitHub
2. Go to [render.com](https://render.com) → **New** → **Blueprint**
3. Connect your GitHub repo — Render detects `render.yaml` automatically
4. In the Render dashboard, set these environment variables (never in code):
   - `DATABASE_URL` — copy from a Render PostgreSQL database
   - `LLM_PROVIDER` — set to `groq` (or `nvidia`, `gemini`, `anthropic`)
   - `GROQ_API_KEY` — your Groq API key (free at [console.groq.com](https://console.groq.com))
   - Any other LLM keys you want to use
5. Deploy → your backend URL will be `https://zeroday-security-ai-backend.onrender.com`

### Frontend → [Vercel](https://vercel.com)

1. Go to [vercel.com](https://vercel.com) → **Add New Project**
2. Import your GitHub repo
3. Set **Root Directory** to `frontend`
4. Add environment variable:
   - `NEXT_PUBLIC_API_BASE_URL` = `https://zeroday-security-ai-backend.onrender.com`
   (replace with your actual Render backend URL)
5. Deploy

### Update CORS After Deployment

Once your Vercel URL is known (e.g. `https://zeroday-ai.vercel.app`), update `ALLOWED_ORIGINS` in your Render backend environment variables:
```
ALLOWED_ORIGINS=["https://zeroday-ai.vercel.app"]
```

## Environment Variables

See [`backend/.env.example`](backend/.env.example) for the full list. **Never commit `.env`**.

| Variable | Required | Description |
|---|---|---|
| `DATABASE_URL` | Yes | PostgreSQL URL (prod) or SQLite path (dev) |
| `JWT_SECRET_KEY` | Yes | 64-char hex secret — auto-generated by Render |
| `LLM_PROVIDER` | Yes | `groq` \| `nvidia` \| `gemini` \| `ollama` \| `anthropic` |
| `GROQ_API_KEY` | If using Groq | Free at console.groq.com |
| `NVIDIA_API_KEY` | If using NVIDIA | Free at build.nvidia.com |
| `GEMINI_API_KEY` | If using Gemini | Free at aistudio.google.com |
| `NVD_API_KEY` | Optional | Increases NVD API rate limit |
